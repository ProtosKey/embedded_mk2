# Калькулятор

Калькулятор целых чисел (`+`, `-`, `×`, `÷`) на стенде SDK-1.1M (STM32F407).

Ввод с клавиатуры стенда, вывод на OLED-дисплей.

## Структура

- `src/`: логика программы
- `drivers/`: драйверы (клавиатура, дисплей, I2C, UART)
- `include/`: заголовочные файлы
- `lib/`: HAL и CMSIS от ST
- `startup/`, `STM32F407VGTx_FLASH.ld`: старт и линкер-скрипт

## Сборка и прошивка

Нужны `arm-none-eabi-gcc` и `openocd`. Стенд подключается через USB DBG.

```
make
make flash
make monitor
```
